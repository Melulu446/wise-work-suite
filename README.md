## 📖 Overview

WorkWise AI is a modern AI-powered workplace productivity platform designed to help professionals automate everyday office tasks using Artificial Intelligence.

The application combines multiple AI tools into a single dashboard, allowing users to generate professional emails, summarize meeting notes, organize schedules, research topics, and interact with an AI workplace assistant.

This project was developed as part of the **CAPACITI AI Programme** to demonstrate practical AI implementation, prompt engineering, responsible AI usage, and modern web application development.

---

# 🎯 Project Objectives

The objective of WorkWise AI is to:

- Improve workplace productivity
- Reduce time spent on repetitive tasks
- Demonstrate the practical use of Generative AI
- Showcase prompt engineering techniques
- Build a responsive SaaS-style application
- Promote responsible and ethical AI usage

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/AI-Productivity-Assistant.git
```

Navigate into the project

```bash
cd AI-Productivity-Assistant
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```
